## 🖨️ Slide Deck Download Notes

### Format Options
- **Option A (Recommended)**: Separate `slides.html` with print CSS — opens print dialog → Save as PDF
- **Option B**: `html2canvas` captures each section → `jsPDF` compiles → downloads as `.pdf`
- **Option C**: Generate a static image grid using canvas screenshots

### Slide Dimensions
```
Web: 1920 × 1080px (16:9 widescreen)
PDF Export: A4 Landscape (297 × 210mm) OR Letter Landscape
```

### Slide Design Consistency
- All slides share same font, color, and header structure
- Slide number bottom right
- LIHF small logo top left or top right
- Section label (small caps, gold) above every main heading
- Bottom footer: "LIHF 2026 | One Culture • One Movement • One Region"
